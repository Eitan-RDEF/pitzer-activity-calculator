# Security policy

## Supported versions

The project has not made a public release. Only the current `main` branch will receive
security fixes during initial development.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Until a dedicated security
contact is published, contact the repository owner privately through the profile associated
with the source repository.

Reports should include reproduction steps, affected inputs, impact, and any suggested
mitigation. Never include sensitive customer solution data.
