# Security policy

## Supported versions

The latest `1.x` release and the current `main` branch receive security fixes. Older tags are
historical snapshots and may not receive fixes.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Contact the repository owner,
Eitan Elfassy, privately at [eitan.elfassi@gmail.com](mailto:eitan.elfassi@gmail.com).

Reports should include reproduction steps, affected inputs, impact, and any suggested
mitigation. Never include sensitive customer solution data.
